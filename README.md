# Kent Flutes

Website for Pam Palmer — flute, piano and music theory tuition in Kent.

Plain HTML/CSS static site, no build step.

## Editing

Open `index.html` — the bracketed placeholders (`[Add ...]`) mark the spots
that need real content: bio, qualifications, rates, email, phone, and area
covered.

## Publishing

Deployed via GitHub Pages from this repo. Push to `main` and enable Pages
in the repo settings (Settings → Pages → Deploy from branch → `main` / root)
if not already enabled, then point the `kentflutes.co.uk` DNS at GitHub Pages.
